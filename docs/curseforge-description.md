# Allemano Hub

**Allemano Hub** is an optional companion for the Allemano addons (Hush, AltBoard, CraftBoard, Allemano Raid Tools, Arbiter Loot Council, Session Tracker). Open it with `/allemano` or `/ah`. None of the other addons need it.

## Overview
- Every Allemano addon you have installed, with its version and a button to open it.
- A banner when a newer version of one of them exists, and a News list with what changed in each release.

## Errors
- Lua errors from all Allemano addons on one page.
- A copy box (`/allemano report`) that builds a bug report with your versions, ready to paste.

## Appearance
- Font, size, accent color, background and scale for the Hub window, plus the minimap/launcher button.
- Uses the Expressway font automatically if EllesmereUI is installed, otherwise the default font.

## Guild
- A table of guildmates who run the Hub and which Allemano addon versions they have, so you can see who is out of date.
- Only addon names and versions are shared, only with your own guild, and "Share my addon list" turns it off.

## Commands
- `/allemano` or `/ah`: open the Hub
- `/allemano report`: build a bug report
- `/allemano sync`: ask the guild for addon lists

Made for WoW Classic Anniversary. Bugs and ideas: github.com/Allemano-Addons/Allemano-Hub/issues
